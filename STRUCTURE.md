## Правила для агента-кодера (обязательные)

1. **Не переписывать готовое.** Файлы со статусом ✅ переносятся как есть и подключаются;
   промпты вида «напиши парсер» означают «адаптируй существующий из parsers/».
2. **Модель не переобучать.** ml/artifacts/ — исследованный ансамбль; задача — прогон
   и экспорт CSV, не тренировка. Переобучение — отдельный процесс с backtest.py.
3. **Правила приоритизации живут только в siar/rules.py.** Формулировки — дословно
   из LOGIC.md §3. Никакой генерации формулировок «на лету» и дублирования порогов.
4. **Инварианты — это тесты.** Каждый инвариант из LOGIC.md §5 существует как pytest;
   нарушение = красная сборка. Выдача отчёта с нарушенным инвариантом запрещена кодом.
5. **Plotly с CDN.** `include_plotlyjs="cdn"` во всех дашбордах (не вшивать 4 МБ библиотеки).
6. **Секреты только в .env.** Никаких ключей и строк подключения в коде и коммитах.
7. **Вежливость к rusada.ru:** запросы не чаще 1 раза в сутки, браузерный User-Agent,
   при смене структуры сайта — ALERT, не молчаливый пропуск.
8. **ФИО не попадают в БД и на дашборды** — работаем на агрегатах вид спорта × регион.
   Пофамильный уровень существует только в исходных xlsx на диске.
9. **Каждый прогон — снапшот:** run_id, дата, версии входных файлов (sha256), версия модели.
10. **Данные не скрывать.** Каждый дашборд и каждая таблица — с селектором
    Топ-10/20/50/все записи; пользователь может добраться до любой записи любого среза.
11. **Расписание:** watcher рейтингов — еженедельно; АД-Монитор — раз в 4 дня
    (промышленный контур; см. LOGIC.md §7 для обоснования); ML-прогон —
    автоматически по появлению новой таблицы дисквалификаций и по закрытию квартала.

## Порядок сборки (этапы)

1. `ml/predict.py` + экспорт model_risks.csv — замыкает цепочку ОСФ (быстрая победа)
2. `siar/rules.py` + доработка osf_report.py под формулировки v2
3. `siar/region_report.py` — сверка с эталонными цифрами (34/14/41 по зонам, средние по ФО)
4. `db/ddl.sql` + loaders + registry_loader.py
5. `monitor/run_monitor.py` (Claude API) + docker-compose с cron
6. `api/` — FastAPI по dashboard.v1
7. `frontend/` — React-платформа + `docs/USER_GUIDE.md` и экран «Справка»
8. `tests/` — сквозным фоном с этапа 2
