# Инструкция пользователя

То же содержание доступно на экране «Справка» внутри платформы — здесь оно продублировано
как отдельный документ (STRUCTURE.md), чтобы им можно было поделиться без входа в систему.

## Зона риска

Зону задаёт прогнозная модель по истории нарушений — рейтинг РУСАДА на неё не влияет.

- 🔴 **Высокий риск** — есть нарушения за последние два квартала подряд.
- 🟠 **Повышенный риск** — нарушения повторяются на длинной истории (два года).
- 🟢 **Низкий риск** — по истории нарушений всё спокойно.
- ⚪ **Нет данных** — прогнозная модель не располагает данными по этой связке.

## Приоритет

Приоритет — это зона риска, сопоставленная с качеством антидопинговой работы (баллом
рейтинга РУСАДА). Таблица соответствия одна для всех связок, исключений нет.

| Приоритет | Условие | Что значит |
|---|---|---|
| 1 | Высокий риск + рейтинг ниже порога | Требует немедленного внимания |
| 2 | Высокий риск + рейтинг высокий | Риск есть, но работа уже ведётся хорошо |
| 3 «потенциальный риск» | Риска по истории нет + рейтинг ниже порога | Может стать рисковым — работа не ведётся |
| 4 | Риска по истории нет + рейтинг высокий | Всё в порядке, плановый мониторинг |

## Матрица (квадранты) и тепловая карта

На матрице каждая точка — федерация или регион: по горизонтали — балл рейтинга РУСАДА,
по вертикали — оценка риска модели. Цвет точки — приоритет. Тепловая карта показывает то же
самое в разрезе «вид спорта × регион».

## Селектор Топ-N

На каждой таблице есть переключатель «Топ-10 / Топ-20 / Топ-50 / Все записи» — данные не
скрываются, любую запись можно посмотреть полностью, а раздел «Выгрузка» отдаёт то же самое
целиком в Excel/CSV.

## «Почему именно так»

Клик по строке или точке открывает карточку с обоснованием: какое правило сработало и какие
фактические цифры за этим стоят, чем подтверждён матчинг с рейтингом РУСАДА, на каких данных
посчитано и сколько сигналов АД-Монитора есть по теме. Текст обоснования всегда пишет код —
искусственный интеллект его не формулирует.

## История рисковости

Архив прогонов не очищается. В разделе «История» можно выбрать связку (вид спорта или регион)
и увидеть, как менялась её зона риска, приоритет и балл рейтинга от квартала к кварталу, а в
режиме «Сравнение» — сопоставить несколько связок между собой на одном графике.

## АД-Монитор

Новостной дайджест обновляется раз в 4 дня, отдельно показывает российский и международный
поток. Письменный обзор пишет ИИ, но только пересказывает уже подтверждённые новости — оценок
риска там нет. Раздел честно показывает, что не подтверждено и какие источники были недоступны.

## Раздел «О данных»

Для внешней проверки: версия модели, дата расчёта, история снапшотов, статус пробелов
АД-Монитора. Повторный расчёт на тех же данных всегда даёт тот же результат.

## Форма пожеланий

Кнопка «Оставить отзыв» есть на каждом экране. Комментарий сохраняется с датой и разделом и
нигде не отображается — ни автору, ни другим пользователям.
