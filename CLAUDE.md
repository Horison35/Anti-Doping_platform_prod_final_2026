# CLAUDE.md · Антидопинговая платформа

Ты работаешь в репозитории антидопинговой системы поддержки принятия решений.

Перед любой задачей прочитай:
1. **STRUCTURE.md** — структура репозитория, статусы модулей, правила для агента-кодера,
   порядок сборки. Файлы со статусом ✅ не переписывать — переносить и подключать.
2. **LOGIC.md** — логика проекта: потоки данных, правила модели и SIAR v2
   с утверждёнными формулировками (§3 — менять запрещено), инварианты (§5 — они же тесты).

Ключевые запреты (полный список — STRUCTURE.md «Правила для агента-кодера»):
- не переобучать модель (ml/artifacts/ — только прогон);
- пороги и формулировки — только из siar/rules.py, дублирование запрещено;
- инварианты из LOGIC.md §5 — обязательные pytest-тесты;
- секреты только в .env; ФИО не попадают в БД и интерфейсы;
- Plotly подключать с CDN; rusada.ru опрашивать не чаще раза в сутки.

Текущий этап сборки смотри в STRUCTURE.md «Порядок сборки».
